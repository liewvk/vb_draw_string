# VB Draw String

A Visual Basic .NET project demonstrating string drawing capabilities using GDI (Graphics Device Interface).

## Overview

This repository contains examples and implementations for drawing strings and text using Visual Basic .NET and GDI graphics.

## Language

- **Visual Basic .NET**

## Getting Started

Clone the repository and open the Visual Basic .NET project in Visual Studio to explore the string drawing examples.

```bash
git clone https://github.com/liewvk/vb_draw_string.git
```

## Features

- String rendering with GDI
- Text formatting and styling
- Graphics output demonstrations

## Usage

Navigate to the project directory and open the solution in Visual Studio to run the examples.
